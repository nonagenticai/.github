# Support

## Where to ask

| You have | Go here |
|---|---|
| A usage question | Open an issue in the repository and say it is a question, or use its Discussions if it has them enabled |
| A bug | The repository's bug report template |
| A feature idea | The repository's feature request template |
| A security vulnerability | **Privately**, through the repository's Security tab — see [SECURITY.md](SECURITY.md). Never a public issue |
| A problem with a fork | The **upstream** project, not this organisation |

## What to expect

These repositories are maintainer-supported, not a commercial support product. There is no
guaranteed response time for questions or feature requests. Security reports follow the
targets in [SECURITY.md](SECURITY.md).

Before opening an issue:

1. Read the repository's README and any `docs/` it has.
2. Search existing issues — someone may have hit it already.
3. Include versions, the exact command you ran, and the full error text. Redact secrets.
